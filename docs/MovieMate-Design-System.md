# MovieMate — Design System v8 (سند مستقل، مرجع نهایی بصری)

**وضعیت**: ✅ قفل‌شده — مرجع رسمی برای هر پیاده‌سازی UI  
**مرجع اصلی**: Linear ALI-76  
**این سند برای این ساخته شده که بدون نیاز به Linear، به‌تنهایی برای شروع کدنویسی UI کافی باشد.**

## ۱. فلسفه‌ی طراحی

Bold · Modern · Clean · Readable · Exciting · بدون چیز اضافی · کنتراست قوی · رنگ‌های قوی و درخشان · Card-based · هر صفحه Task-oriented (یک هدف اصلی) · میکرو-اینتراکشن برای هر اکشن · یکپارچگی کامل (یک design token set برای کل اپ)

## ۲. رنگ‌ها (Color Tokens)

```
Background:      #F1F0EC   (خاکستری گرم، هرگز سفید خالص)
Ink (متن اصلی):   #101012   (تقریباً مشکی)
Ink Secondary:    #6E6E68   (متن کمکی/meta)
Blue (اصلی):      #1F2FE3   (CTA اصلی، عناصر فعال، رینگ آواتار، اعداد آماری)
Blue Dark:        #1826B8   (حالت press/active دکمه)
Lime (ثانویه):    #CCE83B   (تگ‌ها، تزئین، فقط accent دوم)
Coral (تزئینی):   #FF6A46   (فقط تزئینی — هرگز روی عنصر تعاملی)
Paper:            #FFFFFF   (سطح کارت/نوار پایین)
```

**قانون استفاده**: هر صفحه حداکثر ۲ accent همزمان (آبی غالب + لیمویی برای تگ/تزئین). مرجانی همیشه فقط تزئینی است، هرگز روی دکمه یا عنصر قابل‌کلیک.

## ۳. تایپوگرافی

### دو خانواده‌ی فونت
- **Big Shoulders Display** (وزن ۷۰۰/۸۰۰/۹۰۰) — فونت نمایشی، کشیده و بولد. **فقط** برای: هدلاین بزرگ، عنوان فیلم، عدد آماری (مثل "۹۸%")
- **Inter** (وزن ۴۰۰ تا ۸۰۰) — برای همه‌چیز دیگر: متن بدنه، meta، لیبل تگ، متن دکمه، لیبل ناوبری، فرم‌ها

### چرا این ترکیب (تاریخچه‌ی تصمیم)
قبلاً Archivo Black (خیلی عریض) و Anton (خیلی فشرده، در سایز کوچیک ناخوانا) امتحان شد. Big Shoulders Display چون واقعاً condensed طراحی شده (نه فشرده‌سازی مصنوعی)، هم کشیده هست هم خوانا می‌ماند.

### Scale دقیق
```
هدلاین بزرگ (تاریخ/عنوان صفحه):  Big Shoulders 900, 54px, line-height 0.96, letter-spacing -0.5px, UPPERCASE
عنوان فیلم/آیتم:                Big Shoulders 800, 34px, line-height 1.0
عدد آماری (مثل "۹۸٪"):          Big Shoulders 900, 44px, رنگ آبی
توضیح آماری (مثل "shared taste"): Big Shoulders 800, 24px, رنگ ink
متن بدنه:                       Inter 400, 14.5px, line-height 1.55
خط meta:                        Inter 500, 13.5px, رنگ ink-secondary
متن دکمه‌ی CTA:                 Inter 700, 15.5px (⚠️ نه فونت نمایشی — برای خوانایی دکمه)
لیبل تگ pill:                   Inter 700, 12.5px
لیبل ناوبری:                    Inter 600, 11px
```

## ۴. اسکیل فاصله‌گذاری (Spacing — پیکسل‌پرفکت)

```
--s1: 4px   --s2: 8px   --s3: 12px   --s4: 16px
--s5: 20px  --s6: 28px  --s7: 36px
```
همه‌ی padding/margin/gap باید دقیقاً از این اسکیل بیاید — بدون عدد دلبخواهی بینابین.

### رادیوس
```
12px  → چیپ‌های کوچک درون‌خطی
24px  → کارت استاندارد
28-32px → کارت‌های بزرگ/hero
999px → pill (دکمه، تگ، آواتار، نوار ناوبری)
```

## ۵. کامپوننت‌های اصلی

### کارت اصلی صفحه
پس‌زمینه `--bg`، رادیوس ۲۸px، padding `--s6 --s5 --s4`

### تصویر Hero
**نسبت ۱۶:۱۰ (landscape، عریض‌تر از قد)** — این یک اصلاح مهم است؛ پیش‌نویس‌های اولیه اشتباهاً نسبت نزدیک به مربع داشتند. رادیوس ۲۴px.

### تگ‌های Pill (روی لبه‌ی پایین تصویر Hero هم‌پوشان)
با `margin-top: -18px` روی تصویر overlap می‌شوند. دو تگ کنار هم: یکی آبی (متن سفید + دایره‌ی آبی روشن‌تر)، یکی لیمویی (متن ink + دایره‌ی مشکی). فونت: Inter 700, 12.5px.

### ردیف آماری (Stat Row)
اسکریبل لیمویی (SVG دو خط منحنی) سمت چپ + عدد و توضیح با فونت Big Shoulders inline + خوشه‌ای از نقاط مرجانی (۵ دایره، شعاع ~۳px) بالا-راست.

### لوگو‌مارک
دو مربع گردگوشه‌ی هم‌پوشان (آبی بالا-چپ، لیمویی پایین-راست، ۳۴×۳۴px، رادیوس ۱۰px)، هرکدام یک نقطه‌ی سفید کوچک (۵×۵px) در گوشه‌ی بیرونی، به‌علاوه یک ستاره‌ی سفید ۸پر (۱۱×۱۱px) دقیقاً روی محل تلاقی دو مربع.

### آواتار (Stack)
دایره‌ای، ۴۲px، رینگ آبی (۲.۵px)، هم‌پوشانی با `margin: -14px`، هرکدام یک رینگ ۲px هم‌رنگ پس‌زمینه برای جداسازی بصری تمیز از هم‌پوشانی.

### دکمه‌ی CTA
Pill تمام‌عرض، پرشده با آبی، متن سفید Inter 700، padding 17px.

### نوار ناوبری پایین (⚠️ نکته‌ی مهم رفع‌شده)
کانتینر سفید pill (رادیوس ۹۹۹px، padding `--s3 --s2`)، **سه آیتم با ساختار عمودی کاملاً یکسان** (آیکون بالای لیبل، وسط‌چین). آیتم فعال **فقط** با پس‌زمینه‌ی آبی‌روشن (`#E4E7FB`) و رنگ آبی متفاوت است — هرگز جهت چیدمانش عوض نمی‌شود. (نسخه‌ی اولیه این باگ را داشت که آیتم فعال افقی و بقیه عمودی بودند — رفع شد.)

## ۶. آیکون‌ها

- SVG خطی (stroke-based)، گرید ۲۴×۲۴، stroke ۱.۷۵-۲px، گوشه‌های گرد (`stroke-linecap: round`, `stroke-linejoin: round`)
- **هرگز ایموجی به‌عنوان آیکون اصلی UI استفاده نشود** — فقط این ست خطی سفارشی
- ایموجی فقط در جاهای خیلی خاص (واکنش سریع اختیاری بعد از تماشا) مجاز است، نه در ناوبری/دکمه‌های اصلی

## ۷. میکرو-اینتراکشن‌ها (هرکدام زیر ۳۰۰ms)

| اکشن | جزئیات |
|---|---|
| رتبه‌دهی (Taste Dial) | اسلایدر پیوسته، رنگ fill از آبی به لیمویی گرادیانت می‌شود با افزایش عدد |
| فشردن دکمه/کارت | `scale(0.95-0.97)` هنگام press |
| تایید match | کارت با انیمیشن scale-in می‌نشیند + بج چک‌مارک با stroke-draw انیمیشن وارد می‌شود |
| رد کردن پیشنهاد | fade + slide به مرحله‌ی بعد (نه پرش ناگهانی) |

## ۸. اصل کلی برای Claude Code

هر صفحه‌ی جدید UI که ساخته می‌شود باید **از این ۷ بخش بالا مشتق شود**، نه این‌که مقادیر جدید و دلبخواهی معرفی کند. اگر یک کامپوننت جدید لازم شد که در این سند نیست (مثلاً یک نوع کارت جدید)، باید از همین رنگ/تایپ/spacing tokens استفاده کند و بعداً به این سند اضافه شود، نه این‌که جدا از سیستم طراحی شود.
